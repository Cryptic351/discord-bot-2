# LUA STUDIO BOT 2

Discord bot for scripts - Mobile + PC versions.

## Commands
- `!find <name>` - Finds script (shows Mobile 1-tap + PC block)
- `!list` - Lists all scripts
- `!say <message>` - Creator only (makes bot say something)

## Setup
1. Discord Developer Portal -> Bot -> Message Content Intent ON
2. Render -> Environment Variable `DISCORD_TOKEN` = your bot token
3. Start: `python bot.py`

Hosted on Render - UptimeRobot keeps it alive.
